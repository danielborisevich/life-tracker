# Life Tracker

One app for studying, to-dos, calendar, gym/running/tennis, finance and a daily briefing.
Installable on iPhone: open the site in Safari → Share → Add to Home Screen.

- `index.html` – the whole app
- `daily.json` – daily news, word of the day, motivation and medical fact (updated each morning)
- `sw.js`, `manifest.webmanifest`, icons – offline support and home-screen install
